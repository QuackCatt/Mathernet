Learn formulas as a map, not a list.

Mathernet is a local-first study assistant. Describe a formula in plain language and it builds a rendered card, links it into a force-directed knowledge graph with prerequisite and derivation edges, and lets you cut away anything the model got wrong — every relationship traceable to its source.

From a sentence to a study map in three steps

One integration point: your own provider API key (OpenRouter or DeepSeek). Everything else runs on your machine.

Describe

Type what you mean — “the inequality between arithmetic and geometric means”, a LaTeX string, or a half-remembered property. The assistant proposes up to five candidates and you pick the right one.

Connect

The chosen formula becomes a KaTeX-rendered card with a short summary and source links, and the model suggests edges — prerequisite, derivation basis, special case, generalization — into your existing map.

Cut & keep

Suggestions appear immediately as dashed lines. You are the editor: confirm what holds, snip what doesn’t. Deleting a node also cleans up its deep-dive sessions and notes, so nothing stale lingers.

Built for learners who want to inspect everything

Deep dives that stay grounded

Ask for a long-form article on any node and chat about it. Each formula and each relationship keeps its own conversation, and model answers carry the sources they cite.

Multiple mind-map sessions

Keep a probability revision web separate from your analysis notes. Named sessions, per-session graphs, and study statuses (new / learning / reviewed / needs review) tracked per formula.

Honest by construction

Safety rules refuse exam-solving, fabricated derivations and non-formula requests before any API call. Local server binds to loopback with strict Host/Origin checks; data files are written private.

Run it yourself in three commands

No installation beyond Python — Mathernet ships with zero third-party runtime dependencies.

  1. 1
    Clone — git clone https://github.com/QuackCatt/Mathernet (or download the ZIP). Requires Python 3.11 or newer.
  2. 2
    Start — Windows: py .\run_mathernet.py start; macOS / Linux: ./mathernet start. The app opens a local server at http://127.0.0.1:8765 and prints the URL to visit.
  3. 3
    Connect a model — open Settings, choose OpenRouter or DeepSeek, paste your API key. Then describe any formula and watch it appear on your map.

Check the build any time with PYTHONPATH=src python -m unittest discover -s tests (129 tests) and re-score the shipped graph with PYTHONPATH=src python scripts/evaluate_real.py.

Privacy & responsible AI use

Mathernet stores your maps, notes and chats as plain JSON on your own disk and never uploads them. Your API key is sent only to the model provider you configure. Model output is treated as a draft: generated summaries, suggested edges and cited sources are labelled as AI-generated, are editable or deletable by you, and are not independently verified by this tool. It refuses assessed-work solving and fabrication requests locally, before any network call.
