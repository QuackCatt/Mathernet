How it works

From a sentence to a study map in three steps

The only outside connection is the provider API key you supply. Maps, notes and chats stay on your own disk.

Describe

Type what you mean: “the inequality between arithmetic and geometric means”, a LaTeX string, or a half-remembered property. Pick the right formula from the candidates, or reopen one you already saved.

Connect

The chosen formula becomes a KaTeX-rendered card with a short AI summary and any sources the model returned. Suggested dependency edges appear on your map straight away, each with its rationale.

Review & cut

You are the editor. Edges without sources are marked unverified, and any edge that is wrong can be cut from the map. Deleting a node also removes its deep-dive sessions and notes.

Features

Built for learners who want to inspect everything

Interactive knowledge map

A force-directed canvas you can drag, pan and zoom. Selecting a node highlights its neighbours, and nodes are reachable by keyboard.

Several mind maps

Keep a probability revision map apart from your analysis notes. Maps are named, pinnable and deletable, and each shows only the edges between its own formulas.

Deep dives that continue

Ask for a long-form article on a formula or on one relationship, then keep the conversation going. Each one keeps its own saved thread.

Your notes stay yours

AI-generated context and your private notes live in separate places on every card. A study status records activity and is never presented as proof of mastery.

Sources, labelled honestly

Sources are shown as model output. Mathernet adds no citations of its own and does not independently verify the URLs a model returns.

Refuses the wrong jobs

Assessed-work answers, unrelated requests, and requests to fabricate citations or derivations are declined locally, before any API call is made.

The kind of card you will build

Four well-known formulas, shown the way a card presents them: rendered expression, a plain-language gloss, and how it connects to others.

Euler’s identity

$$e^{i\pi} + 1 = 0$$

Links five fundamental constants. It is the special case $x=\pi$ of Euler’s formula $e^{ix}=\cos x+i\sin x$.

special casederivation basis

Markov’s inequality

$$P(X \ge a) \le \frac{\mathbb{E}[X]}{a},\quad X\ge 0,\ a>0$$

The most basic tail bound. Chebyshev’s inequality follows by applying it to the squared deviation.

derivation basis

AM–GM inequality

$$\frac{a_1+\cdots+a_n}{n} \ge \sqrt[n]{a_1 \cdots a_n}$$

For non-negative reals the arithmetic mean is at least the geometric mean, with equality exactly when all terms are equal.

Newton’s method

$$x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}$$

Root-finding by repeatedly replacing $f$ with its first-order Taylor approximation, so Taylor series sits upstream of it.

Run it yourself

No install step. Just Python 3.11 or newer.

Mathernet starts straight from the downloaded folder. Use a current desktop browser; there is no mobile interface.

  1. 1

    Get the code

    Clone the repository or download the ZIP from GitHub and unzip it. Keep the project folder together.

  2. 2

    Start it

    Run the command for your system from inside that folder. Use the exact URL it prints (usually http://127.0.0.1:8765); if the port is busy it picks the next free one.

  3. 3

    Connect a model

    Settings open on first launch. Choose OpenRouter or DeepSeek, paste your API key, and save. Then describe any formula. See the README setup guide for key links.

macOS / Linux
$ git clone https://github.com/QuackCatt/Mathernet
$ cd Mathernet
$ ./mathernet start
# permission error? run: python3 mathernet start
Windows
> git clone https://github.com/QuackCatt/Mathernet
> cd Mathernet
> py .\run_mathernet.py start
# no py launcher? use: python .\run_mathernet.py start

Privacy & responsible use

Your data stays put. AI output stays a draft.

Local by design

Maps, notes and chats are stored as plain JSON on your own disk. Your API key goes only to the provider you configure, and the app is served on your own machine. Saved cards remain usable offline.

Model output is not verified

Summaries, suggested edges and cited sources are AI-generated, editable, and deletable. Mathernet does not check them independently, so uncited answers are visibly qualified. Treat every card as a starting point for your own checking.
