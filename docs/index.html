How it works

From a sentence to a study map in three steps

Mathernet runs on your own computer. Your maps and notes are saved locally, while AI features connect to the provider you choose.

1

Describe

Enter a formula name, a mathematical expression or a description in your own words. Choose the closest match from the suggestions or open a formula you have already saved.

2

Connect

The formula opens as a card with a rendered equation and AI-generated context. The map displays suggested dependency edges with their rationale and any sources returned by the model.

3

Review and edit

Review each dependency edge and its rationale. Edges without model-supplied sources are marked as unverified, and you can cut connections that are incorrect.

Features

Tools to help organise and explore mathematical ideas

Interactive knowledge map

Move, zoom and explore formulas on a visual map. Selecting a formula highlights its related items.

Separate mind maps

Create different maps for different courses or topics, such as probability and mathematical analysis.

Detailed explanations

Explore longer explanations of a formula or a relationship, and continue asking questions in the same conversation.

Personal study notes

Keep your own notes separately from AI-generated explanations. Study status helps record your progress but does not prove mastery.

Sources you can inspect

Sources are provided by the AI model. Mathernet does not independently check whether the returned links are correct.

Responsible use

Mathernet is designed as a learning and organisation tool, not as a way to produce answers for assessed work or fabricate sources.

01 / Overview Illustrative example

Euler’s identity

$$e^{i\pi} + 1 = 0$$
Simple introduction · sample excerpt

Euler’s identity is a special case of Euler’s formula. It brings together the mathematical constants $e$, $i$, and $\pi$ with $1$ and $0$. The equation is often noted for connecting ideas from exponential functions, trigonometry, and complex numbers.

Run it yourself

Get started with Python 3.11 or newer

Download the project folder and start Mathernet from your computer. You need Python 3.11 or newer and a desktop browser. Mathernet does not currently include a mobile interface.

  1. Download the project

    Open the GitHub repository, select Code and choose Download ZIP. Unzip the downloaded folder.

  2. Open the project folder

    On macOS or Linux, open Terminal, type cd and drag the unzipped folder into the window. On Windows, open the folder in File Explorer, type cmd in the address bar and press Enter.

  3. Start the application

    Copy the command for your computer. Keep the Terminal or Command Prompt window open and visit the local URL printed on screen.

  4. Connect an AI provider

    On first use, select OpenRouter or DeepSeek, enter your API key and save the provider settings. See the README setup guide for details.

macOS / Linux
$ ./mathernet start
# If there is a permission error: python3 mathernet start
Windows
> py .\run_mathernet.py start
# If py is unavailable: python .\run_mathernet.py start

Use the exact local web address printed by the application, usually starting with http://127.0.0.1. The port number may be different on your computer.

Privacy and responsible use

Your study data stays local. AI results still need checking.

Local storage

Mind maps, personal notes and saved conversations are stored on your own computer. Your API key is saved locally and is sent only to the AI provider you select when you use AI features.

Check AI-generated information

Formula explanations, suggested relationships and sources may contain mistakes. Mathernet does not independently verify AI-generated information, so check important details with reliable learning materials.
